# AGENTS.md — starptech.com

Personal site of Dustin Deus. Astro 4, vanilla CSS, no framework, no tracking.
Run `pnpm dev` (port 4400) and `pnpm build`.

Documentation lives in [`docs/`](docs/). Read the relevant file before
changing anything it covers:

- [`docs/style-guide.md`](docs/style-guide.md): the visual language (night
  shore, tokens, type, motifs). Read before touching any styles.
- [`docs/homepage.md`](docs/homepage.md): the painting, walker doors, sound,
  and copy rules for the homepage.
- [`docs/writing.md`](docs/writing.md): the writing index, post layout, and
  the diagram family for posts.
- [`docs/development.md`](docs/development.md): commands, sound generation,
  and known gotchas.

Keep this file to references. New conventions go into the matching doc.
